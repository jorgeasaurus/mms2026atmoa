Session Title: 
Graph 101 : Behind the Scenes of Intelligent Automation

  Description:
Microsoft Graph serves as the backbone of Microsoft 365 automation and the foundation for intelligent agents. Gain essential knowledge on using Microsoft Graph with tools like Graph Explorer and PowerShell. Learn to make API calls, securely explore data, and automate tasks while understanding how these fundamentals underpin the capabilities of AI agents. Build trust in automation by confidently leveraging Graph for your solutions.

What you will learn:
 
* Grasp the fundamentals of REST APIs and their significance for Graph and AI agents. 
* Utilize Graph Explorer to discover and test API calls effectively.
* Integrate Graph with PowerShell scripts to enable real-world automation.
* Comprehend how Microsoft Graph serves as the foundation for custom automation and intelligent AI agents.
