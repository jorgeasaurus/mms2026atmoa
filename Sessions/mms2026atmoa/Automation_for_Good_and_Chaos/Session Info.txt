Session Title: 
Automation for Good and Chaos

  Description:
Automation isn’t good or bad. It’s power, and how we use it matters. This session starts with how automation and AI can genuinely help communities, nonprofits, and civic efforts. Then we flip the script and show how those same skills can power clever, real-time shenanigans and just fun chaos. You’ll learn patterns for building automations that make a difference or deliver harmless mischief, all using the same core techniques. 

What you will learn:
 
* Create automations that react in real time to people, events, or environmental signals. 
* Design AI-driven workflows that foster community support or enable clever, well-timed chaos.
* Transform everyday automation skills into tools that benefit people or spark playful mischief.
* Implement practical ideas right away, whether aiding local organizations or creating harmless fun.
