Session Title: 
Don't Brick the CEO's Mac: Building and Automating macOS Labs

  Description:
Testing unverified macOS policies can be risky, especially for executives. Implement a safe, reproducible macOS VM lab on Apple Silicon, utilizing PowerShell 7 for orchestration. Employ Parallels or UTM to create VMs, enroll them in Intune, apply policies, and easily roll back changes. With live demos and a GitHub starter kit, leave with the skills to conduct your testing without worry.

What you will learn:
 
* Understand Apple Silicon's virtualization constraints and choose the right hypervisor (Parallels or UTM) based on budget and needs. 
* Build a fully automated macOS test lab using PowerShell 7 for managing restore images and VM states efficiently.
* Validate high-risk policies like FileVault and Defender through scripted VM enrollment, testing, and rollback processes to ensure safety.
* Utilize the provided GitHub starter kit to enhance your Windows automation skills for effective macOS policy management.
