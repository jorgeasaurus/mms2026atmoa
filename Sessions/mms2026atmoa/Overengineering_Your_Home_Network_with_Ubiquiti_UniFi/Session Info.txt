Session Title: 
Overengineering Your Home Network with Ubiquiti UniFi

  Description:
Transform a mundane home network into a high-performance system using Ubiquiti UniFi. Delve into the latest products, reference architectures, and diverse controller options like CloudKey and self-hosted solutions. Explore advanced features such as site-to-site VPNs, policy-based routing, VLANs, and centralized logging. Embrace the challenge of designing a home network that rivals data center setups, complete with exciting accessories and innovations.

What you will learn:
 
* Architect a UniFi-based home network utilizing reference patterns for routing, switching, Wi-Fi, segmentation, and security similar to enterprise designs. 
* Implement features like site-to-site VPNs and VLAN segmentation while avoiding pitfalls that lead to network outages.
* Determine the best controller option—CloudKey, self-hosted, or HostiFi—and integrate Protect appliances and UniFi’s latest accessories effectively.
* Explore how unique UniFi accessories can enhance home networking experiences, making it engaging and efficient.
