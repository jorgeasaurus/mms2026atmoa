Session Title: 
Windows Operating System Hardening

  Description:
Defend against modern threats as attackers increasingly exploit legitimate access. Learn practical, proven techniques for hardening Windows clients and servers within hybrid and identity-driven environments. This session delves into effective OS-level hardening strategies, tackling local and remote attack vectors, minimizing workstation vulnerabilities across services and networks, and enhancing server defenses for often-overlooked roles, ensuring robust security across all facets of your infrastructure.

What you will learn:
 
* Implement essential OS-level hardening steps necessary for every environment. 
* Identify modern local and remote attack vectors and discover strategies to block them.
* Reduce the workstation surface area by hardening browsers, services, network stacks, and more.
* Explore server-specific hardening patterns for roles frequently neglected in security protocols.
