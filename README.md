# MMS 2026 At MOA Content

This repository contains session materials for MMS 2026 ATMOA.

## Repository Layout

- `Sessions/`: Session-specific folders and related assets.

Each folder under `Sessions/` corresponds to a session title and may include supporting files such as notes, demos, slide assets, and references.

## Getting Started

1. Open the `Sessions/` directory.
2. Select a session folder by name.
3. Review the materials in that folder.

## Notes

- Folder names are intentionally descriptive to map directly to session titles.
- Additional materials can be added to each session folder as needed.
- Sessions were exported using [CopyMMSFiles](https://github.com/AndrewJNet/CopyMMSFiles).
