Session Title: 
From Intune Admin to Cloud Automator: Building Awesome with Azure

  Description:
Transform from an everyday Intune admin to a cloud automation wizard by leveraging Azure Functions, Logic Apps, and Microsoft Graph. Capture the power of these tools to create custom workflows, automate repetitive tasks, and address challenges previously thought insurmountable. Walk through practical examples demonstrating API connectivity and action triggers, ensuring you depart with the confidence and skills to build impactful solutions.

What you will learn:
 
* Achieve exceptional results by expanding beyond native functionality using Azure tools. 
* Implement Azure services securely and in a repeatable manner, ensuring consistent automation.
* Access real-world examples, complete with code snippets to help you visualize solutions.
* Gain the know-how to confidently create and deploy your own cloud solutions with Azure.
